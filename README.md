# NEON//LIVE — 演唱會紀錄 App（正式版 v2）

可以安裝到 iPhone 主畫面的網頁 App（PWA），不需上架 App Store、不需開發者帳號。
紀錄與照片只存在手機本機（IndexedDB），不會上傳。

## 檔案
- `index.html` — 正式版 App（以 06 鉻霓虹設計為基礎）
- `manifest.webmanifest`、`icons/` — 主畫面名稱與圖示
- `sw.js` — 離線快取（只在 https 網址生效）
- `prototypes/` — 6 款設計原型（範例資料，不存檔）
- `legacy/v1.html` — 第一版備份

## 功能
- 新增／編輯／刪除紀錄：藝人、巡演、類型、狀態、開賣時間、日期、場館、城市、座位、票價（單價 × 張數 + 手續費、外幣換算）、評分、同行者、歌單（ENCORE 分隔）、心得
- 上傳照片當票面封面；照片相簿分「座位視角／現場／實體票根」，自動壓縮
- 搶票狀態：想看 → 等開賣 → 已購票 → 已參加，首頁開賣倒數
- 檔案庫：清單／卡片／月曆，搜尋、狀態與類型篩選
- 數據：票價花費、場次、足跡（城市與場館印章）、年度回顧
- 藝人頁、分享圖卡（票根／收據／CD，1080×1920）、加入 iPhone 行事曆
- 10 套背景主題（整個 App 配色一起換）
- 備份匯出／匯入（含照片），可匯入第一版的備份；第一版存在同網址的資料會自動搬移

## 安裝到 iPhone（推薦：免費 https 網址）
1. 電腦打開 https://app.netlify.com/drop（免費註冊）
2. 把整個 `concert-log` 資料夾拖進去，取得 `https://xxxx.netlify.app`
3. iPhone 用 **Safari** 開該網址 → 分享 → **加入主畫面**
4. 之後從主畫面圖示開啟，可離線使用；https 網址下「分享」也能叫出 iPhone 分享選單

> 資料綁定在「網址」上：在 `http://192.168.0.176:8765` 試用時存的資料，**不會**自動出現在 Netlify 網址。
> 要搬過去：舊網址「系統 → 匯出備份」→ 新網址「系統 → 匯入備份」。

## 更新 App
修改後重新拖到 Netlify 同一個站台，並把 `sw.js` 的 `VERSION` 改成新值，iPhone 下次開啟就會拿到新版。
